# DM7 Codex Database Plugin

This repository contains the shareable `dm7-database` Codex plugin. It combines a local Java MCP server with a React management console for safe Dameng 7 queries, controlled mutations, and session-scoped release SQL exports.

The plugin is published through the repo-local marketplace at `.agents/plugins/marketplace.json`. Runtime artifacts live under `plugins/dm7-database`; build outputs and local credentials are excluded from source control.

## Prerequisites

- Windows 11 and Codex Desktop for the initial supported environment
- JDK 21 for builds; generated bytecode targets Java 17
- Maven 3.9.16
- Node.js with pnpm for frontend development
- A locally licensed Dameng 7 JDBC driver supplied by the user

## Repository layout

- `plugins/dm7-database/server`: Java MCP server and local HTTP service
- `plugins/dm7-database/web`: React/Vite management console
- `plugins/dm7-database/scripts`: build, test, and packaging entry points
- `docs/superpowers`: approved design and implementation plan

The distributable plugin never bundles a Dameng JDBC driver or database credentials.
